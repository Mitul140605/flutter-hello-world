# Flutter Hello World

A minimal Flutter application that displays a centered **Hello, World!** greeting using Material 3.

## Requirements

- Flutter 3.10 or later
- Dart 3.0 or later
- A configured Flutter device, emulator, or browser

## Run locally

```bash
flutter pub get
flutter run
```

To run on a specific device:

```bash
flutter devices
flutter run -d <device-id>
```

## Test

```bash
flutter test
```

## Project layout

- `lib/main.dart` — application entry point and UI
- `test/widget_test.dart` — greeting widget test
- `pubspec.yaml` — package metadata and dependencies
